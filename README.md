# Umang Electronics — Premium Home Appliances & Entertainment

Official web application for Umang Electronics, featuring comprehensive consumer electronics, home appliances, audio-visual tuning, authorized warranty, and product catalog showcase.

## Live Website
- **Production URL:** [https://umang-electronics.vercel.app](https://umang-electronics.vercel.app)
- **Repository:** [https://github.com/luck2503y/Umang-Electronics-web-clone](https://github.com/luck2503y/Umang-Electronics-web-clone)

## Tech Stack
- **Framework:** React 18, Vite
- **Styling:** Tailwind CSS, Custom responsive animations
- **Smooth Scroll:** Lenis
- **Animations:** Lucide React, CSS Transitions & Keyframes
- **Deployment:** Vercel
